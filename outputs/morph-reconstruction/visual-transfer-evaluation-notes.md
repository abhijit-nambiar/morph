# Visual similarity and edit transfer

This is a preliminary test of whether image-feature similarity is useful when choosing an edited reference. For each held-out original, we select the closest other original in its proposed chronological scene using local Vision feature distance, then apply the mapping fitted from that reference and its supplied edit. We compare against the prior fixed representative for the same held-out photo. The held-out edit is used only to score the result, not to choose a reference.

On 38 held-out photos from eight proposed scenes, nearest-reference selection had mean RGB RMSE 0.0584 versus 0.0664 for the fixed representative. It improved 17, worsened eight, and chose the same reference or tied on 13. Restricting choices to the image-based subgroup left 32 eligible photos: mean error was 0.0583 versus 0.0655, with 16 improved, eight worsened and eight tied; six photos had no other eligible edited example in their visual subgroup. Those two comparisons use different photo sets and cannot isolate the effect of subgrouping.

This test selects a potentially different reference and mapping per held-out photo. It therefore tests reference selection, not whether a single shared edit is consistent across a scene. It also assumes the selected reference has an edited counterpart. The images, threshold and group proposals were inspected using this album, groups and pair alignment are unverified, and human edits may have different intentions. Reduced-resolution RGB RMSE is not visual quality; the results do not establish generalization. Sources were matched to the feature run using hashes and edited-file hashes were recorded for reproducibility.
