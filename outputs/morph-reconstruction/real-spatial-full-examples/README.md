# Full-resolution real-pair examples

Each folder contains the representative source and its human edit used to fit the mapping, followed by a different held-out scene photo, its human edit, and two recovered edits applied to that held-out source.

The images are full-resolution JPEGs. Fitting and RMSE comparison used downsized images before JPEG encoding. Selection used the most favorable and least favorable spatial-versus-polynomial error differences in this album; it is not a representative sample. Groups and pair alignment are unverified, and human edits can vary by photo. The spatial mapping uses a frame-relative light mask.
