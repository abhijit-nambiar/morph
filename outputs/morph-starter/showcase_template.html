Local lighting exists in separate experimental workflows. The three looks in this album use global color and tone with per-photo normalization.

Used in this -photo showcase

Global edits + photo correction

Each photo gets an estimated tone/color correction, then its scene’s saved style. These operations apply across the frame. Faces and people are not separately selected in the three styled albums.

Separate experiments · not active in these albums

Face regions + person masks

The face workflow adds soft light around detected face boxes. The person workflow uses soft segmentation masks to change light on people, including clothing. Each has its own fitting and replay path.

Where it fits: a subject-aware mapping can combine a global look with a local light component during fitting and replay. That route needs detections or masks for every frame. Masks can miss distant people or include background; face regions also affect nearby pixels. The earlier 13-photo person experiment was rendered and reviewed separately. It has not been combined with the normalization and three-look run shown here.

02 / Recover the edit

A target look.
An executable approximation.

The fitter sees the image pair. It learns the visual change, then saves a small mapping that can be applied again.

The target is an agent-authored deterministic style, created with tone curves and color-range adjustments. The recovered mapping is a separate cubic RGB model, selected against the existing renderers on validation frames.

Presenter notes

Point to the target and reconstruction, then switch among all three styles. Fitting uses a reduced representative image; replay uses each full-resolution source. The target editor's settings are withheld from the fitter. The mapping approximates the resulting appearance; it does not identify a unique original slider recipe.

04 / Normalize the light

Stress the input.
Keep the intent.

Scene-wide shifts and individual camera-setting differences are injected before processing. The correction stage estimates them from image content.

Exposure offsetsWarm / cool shiftsContrast variation

Controlled normalization test

less error relative to the intended reference baseline

The evaluation baseline is the normalization result on the unperturbed album. This measures stability under injected variation. Intended references establish absolute exposure and color.

How normalization and album consistency are tested

Only the varied album and one designated reference per lighting group enter normalization. The other clean photos and applied variance settings are used by a separate evaluator. It compares normalized outputs with the reference-calibrated clean baseline, measures residual bias per scene, and checks the spread of those biases across the album. The synthetic curves model global settings changes. Local shadows, clipped detail and artistic judgments need separate evaluation.
